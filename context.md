# Prism IQ — Project Context & Roadmap

Prism IQ is a production-grade full-stack emotional AI chatbot and data intelligence assistant designed to guide users from raw data to business decisions through an automated, pipeline-driven workflow.

---

## 1. Current Implementation Status

### ✅ Backend (Feature-Complete for Core Pipeline)
* **Authentication & User Management**: SQLite/PostgreSQL users table schema, password hashing, and JWT authorization session endpoints (`/auth/register`, `/auth/login`, `/auth/me`).
* **Dataset Ingestion**: Robust parser for CSV and Excel files, storage structure under `uploads/raw/`, and dataset metadata versioning.
* **Data Profiling**: Auto-profiling calculating missing values, duplicates, column type summaries, and data quality scores.
* **Smart Cleaning**: Rule-based cleaning applying imputation, categorical standardization, duplicate removal, and outlier adjustments, writing results to `uploads/cleaned/`.
* **Exploratory Data Analysis (EDA)**: Statistical summaries and distribution arrays optimized for charts rendering.
* **AI Insights**: Rule-based intelligence engine generating high/critical severity observations and recommendations.
* **Dashboard Engine**: Aggregation service serving KPIs, timeline logs, quality charts, and recent activity list.

### ⚠️ Backend (Block 9 & ML — Pending Finalization)
* **Report Schema Migration**: Database model for `reports` is created but the Alembic database schema migration has not been generated or applied.
* **Export Engine Code**: Core PDF, Excel, HTML, and JSON export scripts are drafted in the service layer, but need metadata enhancements and strict status lifecycle integration.
* **Machine Learning (ML)**: ML directories (training, inference, evaluation) are currently placeholders. The actual ML pipelines (Classification vs. Regression auto-detection, models training, prediction API) are scheduled for later.

### ❌ Frontend (Vite + React + Tailwind)
* **Codebase Structure**: Tailwind, PostCSS, and Vite configs are set up, but all components, routing, states, and layouts are empty placeholders.
