# Prism IQ

Prism IQ is a production-grade full-stack emotional AI chatbot and data intelligence assistant.

## Tech Stack
- **Frontend**: React, Vite, Tailwind CSS, TypeScript, shadcn/ui, Recharts
- **Backend**: Python FastAPI, WebSockets, Uvicorn
- **Database**: PostgreSQL (SQLAlchemy Async) + Supabase
- **Cache**: Redis for session memory
- **AI Models**: Local inference models

## Development Workflow
1. **Import Dataset**: Load files (CSV/Excel) or scrape online data sources.
2. **Profile**: Audit column types, statistical distributions, and detect problems.
3. **Clean**: Handle missing values, outliers, duplicate records, and type conversions.
4. **Explore (EDA)**: Generate correlation analyses, statistics, and charts.
5. **Train**: Apply local ML pipelines for prediction, classification, or forecasting.
6. **Insights**: Extract emotional and semantic indicators from user queries.
7. **Report**: Compile PDF/JSON summaries of findings.
